How Train-a-Bot Arcade works

The game

  • Your robot races up a 5-lane neon road. Switch lanes with ←/→ (or A/D).
  • Red firewalls end your run. That includes sliding into one that's right beside you.
  • Each row you survive is +1 and each yellow power cell is +10.
  • It speeds up the longer you last. Hard mode is fast and crowded.
  • Each named track uses a fixed seed, so the walls show up in the same places every time, for you and for the bot.

Keys

Space start/retry · P pause · T train · W watch bot · 123 tabs · M mute · H help · Esc close

How the bot learns (Q-learning)

  • What it sees: how far away the next firewall is in its own lane and the two lanes on each side (up to 4 rows ahead), plus which way the nearest power cell is. That adds up to 12,500 possible situations.
  • What it gets: +1 for each row, +10 for each cell, -100 for a crash.
  • The cheat sheet: for every situation it keeps a score for Left, Stay and Right. After each move it nudges that score toward "what I got + how good the next situation looks."
  • Curiosity: it starts out making 100% random moves so it can explore. As it gains experience it trusts the cheat sheet more, down to 2% random.
  • Mirror trick: each lesson is also learned flipped left-to-right, which doubles what it learns from every run.
  • Checkpoints save copies of its brain along the way so you can watch it go from Newborn to Legend.
